CineArchive is a minimalist digital application designed to help you catalog, explore, and reflect on your cinematic journey.
https://sharonjeyakumar.github.io/cinearchive/


Step 1: Create your free OMDB Api key and add it to the input box at the top. https://www.omdbapi.com/apikey.aspx
Step 2: Enter Movie title, your rating and notes and click add to collection.
